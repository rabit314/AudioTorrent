# Known Bugs and Investigation Log

**No application runtime has been tested in this template.** Therefore, no actual application bugs are asserted here.

## Bug report template

```markdown
### BUG-001 — Summary
Status: OPEN | INVESTIGATING | FIXED_UNVERIFIED | VERIFIED | WONT_FIX
Reported by: Agent / Model / Role
Observed at: ISO timestamp with offset
Related tasks/plans: TASK-XXX / PLAN-XXX
Environment: OS, app version, dependencies, build
Reproduction: Exact steps
Expected vs actual: What should happen vs what did happen
Evidence: Logs, stack trace, file/line (redact secrets)
Root cause: Confirmed or suspected (label clearly)
Attempts: What was tried and why it failed/succeeded
Fix: Commit/diff, if applicable
Verification: Exact test result and who ran it
```
