# Plans

`PLAN.md` in the project root is the **original project plan provided with the Android app**. Preserve it as the user's source document until changes are explicitly approved.

`PLAN-001_existing-android-audit.md` is a proposed **planning/review task** to assess the current implementation, not to overwrite existing source.

`ARCHIVED/initial-scaffold-PLAN-001_mvp-architecture.md` preserves the initial generic scaffold plan, written before the actual Rivulet source was provided. It is **superseded by the current project context** and must not be used as the active implementation plan.

Use `_TEMPLATE.md` for future plans. Always list ID, version, author, role, dependencies, assumptions, steps, acceptance criteria, test plan, risks, approval and handoff. Implementers must record the exact approved version they followed.
